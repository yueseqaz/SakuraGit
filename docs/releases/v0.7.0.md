# SakuraGit 0.7.0 — Repository Editor / 仓库编辑器

## 中文

- 同窗口代码编辑器：按目录懒加载的文件树、路径打开、多文件标签及独立撤销/选择状态。
- CodeMirror 6 行号、语法高亮、折叠、括号匹配、自动缩进、查找替换与语言组件提供的基础补全。沿用四款主题和代码字号。
- 从工作文件 Diff 进入编辑，保存后查看 Diff 再自行暂存/提交。Cmd/Ctrl+S 仅写工作区，不自动暂存或提交。
- 保存前校验内容/权限版本、备份原文件；拒绝覆盖外部修改。关闭或重新读取脏文件需要确认；草稿尽力缓存于本机，退出时提醒。
- 支持已有普通 UTF-8 文件，最大 1 MB；保留 LF/CRLF、BOM、最终换行和权限。拒绝混合/旧式换行、二进制、符号链接、Git 元数据及嵌套仓库。每目录最多显示 2000 项，最多打开 16 个文件。

仍为早期预览版。没有完整 IDE 的语言服务器、调试器、项目类型检查和文件新建/删除/重命名。缓存不是备份保证；草稿和原文件备份可能包含敏感文本，只在本机保存，不自动清理或上传。构建和测试全部在 GitHub 执行，跨编译不代表 ARM 真机验证。

## English

- Same-window repository editor with lazy directory browsing, relative-path opening, multi-file tabs and independent undo/selection state.
- CodeMirror 6 line numbers, highlighting, folding, brackets, indentation, search/replace and language-dependent basic completion, integrated with all four themes and code font size.
- Open worktree files from Diff; save, inspect changes, then stage/commit explicitly. Cmd/Ctrl+S never stages or commits.
- Revision-checked, backed-up saves reject external edits; dirty close/reload confirmations, best-effort local draft caching and native exit protection.
- Existing regular UTF-8 files up to 1 MB; LF/CRLF, BOM, final newline and permissions preserved. Mixed/legacy line endings, binaries, symlinks, Git metadata and nested repositories are refused. At most 2,000 entries per directory and 16 open files.

Early prerelease, not a full IDE: no LSP, debugger, project-wide type analysis or file creation/deletion/rename. Draft caches are not reliable backups; drafts/pre-save backups may contain sensitive content and remain local without automatic cleanup/upload. All builds/tests run on GitHub; cross-compilation does not establish ARM-device validation.
