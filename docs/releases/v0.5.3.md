# SakuraGit v0.5.3 — Built-in Terminal / 内置终端

## New / 新功能

- Open an interactive, native MyGo/Ghostty terminal from the workspace toolbar, Development Tools, or Ctrl/Cmd + backtick. / 从工作区工具栏、开发工具或 Ctrl/Cmd + 反引号打开原生交互式终端。
- Starts in the selected repository; reopening focuses its existing session. Up to eight repository terminals may be open. / 默认从当前仓库目录启动；重复打开会聚焦已有会话，最多同时打开八个仓库终端。
- PTY/ConPTY input, ANSI colors, Unicode, scrollback, resizing, copy/paste and font zoom. / 支持真实终端输入、颜色、中文、滚动、窗口缩放、复制粘贴和字号调整。
- Confirm before closing live sessions or exiting; wait for attached programs to terminate. A shell that exits leaves its output visible. / 关闭会话和退出应用前先确认并等待关联程序结束；Shell 自行退出后保留输出。
- Bundled terminal libraries are checked for the target architecture alongside the app. / 终端运行库随应用打包，并与主程序一起检查目标架构。

## Safety And Requirements / 安全与环境要求

This is a real shell: commands are unrestricted and can modify or delete files. No commands or repository scripts are sent automatically by SakuraGit; user shell startup files still run. Terminal-protocol clipboard reads/writes are denied, while explicit copy/paste works. Detached background processes are not guaranteed to stop when the window closes. SakuraGit does not persist terminal output; the shell may keep its own history.

这是真实 Shell，命令不受 Git 按钮限制，可以修改或删除文件。SakuraGit 不自动发送命令或执行仓库脚本；用户自己的 Shell 启动配置仍会执行。终端协议的剪贴板读写默认禁止，手动复制粘贴正常。关闭终端不保证结束已经脱离终端的后台进程。应用不保存输出，Shell 自身可能保存命令历史。

- macOS **13+**, Intel/Apple Silicon universal DMG; ad-hoc signed, not notarized. / macOS 13+ 通用 DMG，未做 Developer ID 签名或公证。
- Windows **10 1809+**, x64/ARM64 setup EXE; requires WebView2 and system Git, unsigned. / Windows x64/ARM64 安装程序，需要 WebView2 和系统 Git，未签名。
- Linux x64/ARM64 DEB or tar.gz; glibc 2.28+, GTK 3, WebKitGTK 4.1 and system Git. / Linux 需相应图形运行库和 Git。
- macOS/Linux use the user's login shell; Windows prefers PowerShell. No shell picker, docked panel, terminal tabs or session recovery yet. / 暂无 Shell 选择器、底部面板、多标签页或会话恢复。

All packages are built on GitHub-hosted runners, not on the developer's computer. Windows/Linux ARM64 are cross-compiled; automated PTY tests and successful builds are not full graphical/device validation. No in-app updater is enabled. SHA256SUMS detects corrupted downloads; it is not an independent code-signing guarantee.

所有分发包均在 GitHub 托管 runner 上编译。Windows/Linux ARM64 为交叉编译，自动终端测试与构建通过不代表完成全部图形交互或目标设备实测。未启用应用内自动更新。SHA256SUMS 用于校验下载完整性，不等于独立的代码签名保证。
