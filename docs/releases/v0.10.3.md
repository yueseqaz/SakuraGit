# SakuraGit 0.10.3

## 中文

- 提交图谱按所有连线计算宽度，包含尚未加载的父提交，不再固定裁剪到 116px。
- 图谱列根据历史面板宽度自适应，提交标题、作者和日期保持独立对齐。
- 分支较多时，支持图谱独立横向滚动、方向按钮以及触控板操作；选中提交时自动显示对应节点。
- 补充分支密集场景、面板缩放、分页连续性及明暗主题的回归验证。

## English

- Size the commit graph from every ancestry lane, including unloaded parents, instead of clipping it to 116px.
- Adapt the graph column to the history panel while keeping commit metadata independently aligned.
- Scroll wide graphs independently using the scrollbar, arrow buttons, or trackpad; automatically reveal selected commit nodes.
- Add regression coverage for dense branch histories, panel resizing, pagination continuity, and light/dark layouts.
