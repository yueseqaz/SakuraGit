# SakuraGit 0.8.0 - Local Development / 本地开发工具

## 中文

- 编辑器增加二进制只读预览：每页 4 KB 的十六进制 / ASCII；PNG、JPEG、GIF 支持最大 4 MB、1600 万像素的图片预览。保持路径隔离，不写入或暂存文件；翻页读取当前磁盘，不是固定快照。
- 自动读取 macOS / Linux 登录 Shell 的开发路径，Windows 读取用户 / 系统环境。检测 Java / javac、Go、PHP、Node、npm、pnpm、Yarn 和 Composer 的路径与版本；不会安装工具或修改系统环境变量。
- 顶部「快捷启动」、设置「配置开发环境」：按仓库保存命令、相对工作目录和环境变量覆盖。保存不会执行命令；确认完整命令后，在同窗口底部独立终端标签启动。保留 Ctrl+C、退出状态、关闭确认及输出。
- 配置保存在本机应用数据目录，不读取仓库任务配置或项目 .env。环境值按字面使用；自定义值明文落盘，不建议存放密钥。环境刷新会执行用户 Shell 启动配置和工具版本命令；快捷命令拥有当前账号权限，不是沙箱。

仍为早期预览版。二进制只读，不提供十六进制写入、PDF/Office 文档渲染或音视频播放。不会恢复重启前的终端进程；环境覆盖仅用于后续新会话，普通交互 Shell 自身的启动配置仍可能覆盖变量。构建与测试在 GitHub 执行。

## English

- Read-only binary browsing in 4 KB hex/ASCII pages, plus PNG/JPEG/GIF previews up to 4 MB and 16 million pixels. Confined file access, no writes/staging; pages read the current disk, not an immutable snapshot.
- Capture login-shell development paths on macOS/Linux and user/machine environment on Windows. Discover Java/javac, Go, PHP, Node, npm, pnpm, Yarn and Composer paths/versions without installing tools or changing system variables.
- Quick Launch and Settings entries manage per-repository local commands, relative working directories and environment overrides. Saving never runs a command. Review the complete script before starting a separate tab in the existing bottom terminal; Ctrl+C, exit output and close confirmation remain available.
- Configuration stays in the local application-data directory, never imported from repository tasks or project .env files. Override values are literal and stored in plaintext; do not store secrets. Detection runs user shell startup configuration and tool version commands. Commands have your account permissions, not a sandbox.

Early prerelease. No binary writes, PDF/Office rendering or audio/video playback. No terminal process restoration after restart. Overrides affect new sessions; an ordinary interactive shell's own startup files may override them. Builds/tests run on GitHub.
