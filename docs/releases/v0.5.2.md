# SakuraGit v0.5.2 · Early Access / 早期预览

SakuraGit is a lightweight, local-first Git desktop client built with MyGo, Go, React, and TypeScript. This release introduces the SakuraGit name, bilingual documentation, and GitHub-hosted cross-platform builds.

SakuraGit 是基于 MyGo、Go、React 和 TypeScript 的轻量 Git 桌面客户端。本次版本统一使用 SakuraGit 名称，提供中英文文档，并通过 GitHub Actions 构建跨平台安装包。

ARM64 Windows/Linux packages are cross-compiled on same-OS x64 runners; a successful build is not an ARM64 device or GUI validation.

所有附件均由 GitHub 托管 runner 从此标签构建，不使用开发者本机安装包。打包前在 macOS、Windows 和 Linux 上运行自动测试。Windows / Linux ARM64 包由同系统 x64 runner 交叉编译；编译通过不等于完成 ARM64 设备或图形界面实测。

## Highlights / 主要功能

- Clear staged / unstaged changes, hunk staging, and per-repository commit drafts. / 已暂存与未暂存分区、代码块暂存、按仓库保存提交草稿。
- Unified and side-by-side Diffs with syntax and intraline highlights. / 统一与并排 Diff、语法高亮和行内修改高亮。
- Automatically paged commit history, visible authors, and full-history search. / 历史滚动自动加载、直接显示作者、全历史搜索。
- Persistent resizable panels and mist-blue / graphite light and dark themes. / 可记忆的拖动面板、雾霾蓝与石墨灰浅深主题。
- Branch, Stash, remote, conflict workflow, progress, and cancellation tools. / 分支、Stash、远程、冲突流程，以及进度与取消。
- Existing Gitlane settings and drafts keep their compatible storage namespace. / 兼容旧版 Gitlane 的配置与草稿存储。

## Requirements And Warnings / 环境要求与注意事项

- **Git must be installed and discoverable.** / 必须安装系统 Git，并确保应用可以找到它。
- macOS uses system WKWebView. The app is **ad-hoc signed, not Developer ID signed or notarized**. Gatekeeper may block a downloaded build; only approve software you trust through macOS security controls. / macOS 使用系统 WKWebView；仅 ad-hoc 签名，未完成 Developer ID 签名或公证，下载后可能被 Gatekeeper 拦截，请仅通过系统安全入口批准你信任的应用。
- Windows needs **Microsoft Edge WebView2 Runtime**. Installers are **not Authenticode signed** and may trigger SmartScreen. / Windows 需要 WebView2 Runtime，安装程序未做 Authenticode 签名，可能出现 SmartScreen 提示。
- Linux needs a graphical desktop, **GTK 3** and **WebKitGTK 4.1**. Debian packages declare these dependencies plus Git. For tar archives, install the runtime libraries yourself. / Linux 需要图形桌面、GTK 3 和 WebKitGTK 4.1；Debian 包声明这些依赖以及 Git，压缩包用户需自行安装运行库。
- UI is currently primarily Chinese. This is an early preview, not a production-readiness guarantee. / 界面目前以中文为主；本次为早期预览，不代表已完成生产级验证。
- Live authentication, GUI workflows on Windows/Linux, and every target device are not exhaustively tested. No auto-update system is enabled. / 在线认证、Windows / Linux 图形交互及所有目标设备尚未全面实测，未启用应用内自动更新。
- Cancellation is not rollback. Inspect repository state after an error or cancellation and open trusted repositories only. / 取消不等于回滚，出错或取消后请检查仓库状态，仅打开可信仓库。

## Verify Downloads / 校验下载

Download `SHA256SUMS` alongside your package, then compare the corresponding digest:

下载校验文件并核对对应安装包的摘要：

```sh
# Linux: checks every downloaded file named in the list; absent files are ignored.
sha256sum --ignore-missing -c SHA256SUMS

# macOS: compare the DMG's SHA-256 with its SHA256SUMS entry.
shasum -a 256 SakuraGit-0.5.2-macos-universal.dmg
```

```powershell
# Windows: compare with the matching SHA256SUMS entry.
Get-FileHash .\SakuraGit-0.5.2-windows-amd64-setup.exe -Algorithm SHA256
```

SHA-256 checksums detect changed/corrupted downloads; they are not a code-signing certificate or an independent authenticity guarantee. / 校验和用于检测文件变化或损坏，不等同于代码签名或独立的真实性保证。
