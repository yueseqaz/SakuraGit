# SakuraGit 0.10.4

## 中文

- 顶部新增侧栏收纳按钮，支持 Cmd/Ctrl+B 切换，释放工作区宽度；输入框与代码编辑器的快捷键不受影响。
- 提交历史新增展开模式，可暂时收起右侧详情，让图谱和提交信息独占工作区。
- 记住侧栏与历史展开状态，保留原有拖动宽度和提交选择。
- 图谱随可用宽度重新布局；窄窗口中保留提交日期，展开模式显示提交 ID。
- 增加布局持久化、快捷键隔离、密集图谱和移动宽度的回归验证。

## English

- Add a top-bar sidebar toggle and Cmd/Ctrl+B shortcut to reclaim workspace width without intercepting text-editor shortcuts.
- Add an expanded history mode that temporarily hides commit details and gives the graph and metadata the full workspace.
- Persist both layout states while preserving split widths and the selected commit.
- Reflow the graph with available space, retain dates in narrow windows, and show commit IDs in expanded desktop history.
- Cover layout persistence, shortcut isolation, dense graphs, and mobile widths with regression checks.
