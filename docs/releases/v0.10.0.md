# SakuraGit 0.10.0

## 中文

- 修复内置终端将 `TERM` 设为 `dumb` 导致 Starship 提示错误的问题，终端现在使用 `xterm-256color`。
- 终端工具栏改用图标按钮，保留悬停提示和无障碍标签。
- 限制提交历史图谱的最大列宽，分支较多时提交标题、作者和日期仍保持可见。
- 开发工具会根据 `package.json`、`go.mod`、Maven、Gradle、Composer 和 Python 清单识别项目，并生成安装、运行、测试和构建命令。
- 支持 OpenAI 兼容接口和本地 Ollama 等自定义 AI 供应商。AI 只接收项目类型和脚本元数据，不读取源代码；命令仍需明确点击后运行。

## English

- Fix Starship's `TERM=dumb` warning by launching the embedded terminal with `xterm-256color`.
- Replace terminal toolbar text buttons with icon controls while keeping tooltips and accessible labels.
- Bound the commit graph column so wide branch fan-out cannot hide commit subjects or author metadata.
- Detect Node.js, Go, Maven, Gradle, Composer and Python projects and suggest install, run, test and build commands.
- Add custom OpenAI-compatible and local Ollama providers. AI receives project and script metadata only; commands still require an explicit click.
