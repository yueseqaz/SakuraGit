# SakuraGit 0.9.0

## 中文

- 使用 Radix UI Colors 重构四套主题及浅色/深色模式，统一工作台、Diff、编辑器、提交图与内置终端的默认颜色。
- 统一 12 / 14 / 18 px 字号和 0.5 px 网页组件边框，优化工具栏、主题选择和嵌套圆角。
- 清理中点分隔符、宣传式标题及重复说明，移除装饰动画、阴影和左侧色条。
- 已保存的快捷命令点击运行后直接启动，保存不自动运行；危险 Git 操作、丢弃编辑和关闭运行中终端仍需确认。
- 兼容已有仓库、设置、草稿和备份。历史代码字号迁移为 12 / 14 px。

## English

- Rebuild all four light/dark palettes with Radix UI Colors, including editor, diff, commit graph and native terminal defaults.
- Use 12 / 14 / 18 px typography and 0.5 px web component borders, with aligned controls and restrained nested radii.
- Remove middle-dot separators, promotional headings, repeated explanations, decorative animations, shadows and colored card stripes.
- Run saved quick commands with one explicit click. Saving never runs scripts; destructive actions and running-terminal closure keep their guards.
- Preserve repositories, settings, drafts and backups. Legacy code sizes migrate to 12 / 14 px.

Builds and automated validation run on GitHub-hosted runners. macOS is ad-hoc signed and not notarized; Windows installers are unsigned. OS dialogs and terminal-hosted applications retain platform/application rendering, including their own true-color output. Cross-platform packaging does not establish full physical-hardware validation.
