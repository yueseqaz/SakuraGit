# SakuraGit 0.6.0 — A Git Workbench / Git 工作台

## 中文

- **同窗口终端**：MyGo 原生布局内嵌现有 WebView 与 Ghostty，终端不再另开窗口。支持多会话标签、按仓库隔离、拖动高度并保存、最大化 / 恢复和收起；收起不结束程序。确认对话框临时让出终端空间，保留会话。
- **工作台与主题**：紧凑工具栏、更多 Diff 空间，四款主题（雾霾蓝、石墨灰、苔原绿、暖砂纸）均支持浅色 / 深色 / 系统，同步终端配色。
- **Diff**：按行暂存 / 取消暂存，保留按块和整文件操作；新增上一个 / 下一个改动导航与 F7 / Shift+F7。位置和版本由后端校验，不接受前端任意补丁。
- **三方合并**：Base / Ours / Theirs 对照、结果编辑、逐块采用一侧或保留双方、合并草稿缓存。保存前检查版本及标记、备份原文件并暂存；不自动提交。仅限普通双方修改的 UTF-8 文本，每个版本 ≤1 MB，特殊冲突使用外部工具。
- **撤销与恢复**：撤销末次普通本地提交（Soft Reset，拒绝本地已知已推送提交）、单文件备份后恢复、将备份恢复到工作区。历史中新增 Cherry-pick / Revert 的明确确认。
- **同步指引**：明确展示本地已知的同步 / 待推送 / 待拉取 / 分叉状态，错误提示提供冲突检查和底部终端入口；不强推、不自动合并、不跳过 hooks。

构建与测试全部在 GitHub 执行。自动化包含真实临时仓库的索引/工作区保护、三平台 PTY 和原生终端渲染，以及模拟 IPC 的浏览器布局/交互测试；不等于完整真实桌面、在线认证或 ARM 设备验证。终端内容和 PTY 不在重启后恢复，已脱离终端的后台进程不保证被结束。应用仍处于早期开发阶段。

## English

- Embed MyGo's WebView and native Ghostty terminal in one window, with per-repository session tabs, saved dock height, maximize/restore and collapse without terminating programs.
- Compact workbench chrome and four light/dark/system palettes, including mist blue, graphite, forest and warm sand, coordinated with the native terminal.
- Selected-line staging/unstaging alongside file/hunk operations, plus previous/next change navigation and F7 / Shift+F7. The backend derives patches from a revision-checked diff.
- Integrated Base/Ours/Theirs comparison, editable merge results, per-block choices, cached drafts and pre-save backups. Save stages but never auto-commits; only regular UTF-8 modify/modify conflicts up to 1 MB per version are supported.
- Guarded soft undo of ordinary last local commits, backed-up file restoration, backup recovery, and confirmed Cherry-pick/Revert from history.
- Explicit locally known sync/divergence states and actionable error entry points. No force pushes, automatic merges or skipped hooks.

All builds and tests run on GitHub. Temporary-repository tests, three-OS PTY/native renders and mocked-IPC browser tests are not comprehensive real-desktop, live-authentication or ARM-device validation. No PTY restoration after restart; detached programs may survive shutdown. Early-development prerelease.
